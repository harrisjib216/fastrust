## Verdict

Its 2023 dashboard showed 6.0x faster encoding and 8.5x faster decoding than the base64 crate on large inputs. base64 0.23 (2026-07) added its own AVX2/NEON engine measured at 3.8x encode and 7.1x decode over its scalar path, so most of that gap is gone for callers who opt in. No head-to-head has been published since, and base64-simd has had no release since 0.8.0 (2022-12).

**Why tier C:** First-party dashboard generated by CI; benchmark code is public but the CPU and toolchain are not stated.

## Use it when

- Projects pinned to base64 0.22 or older that need SIMD now
- Forgiving (whitespace-tolerant) decoding at SIMD speed, which base64-simd offers and the dashboard measured

## Skip it when

- You can use base64 0.23+ and construct its Simd engine
- You want an actively released crate: the last base64-simd release is 0.8.0 from 2022-12-28

## How it is fast

Uses the vectorized base64 algorithms of Wojciech Muła and aqrit cited in the README, compiled for AVX2, SSSE3, NEON and wasm simd128 and chosen at runtime, with a scalar fallback.

## What it costs

- The README says the project relies heavily on unsafe code

## Problems with the evidence

- First-party numbers from 2023-04 with no hardware stated
- The base64 version compared is not named; it predates base64's SIMD engine
- The dashboard issue was closed and moved to Nugine/simd-benches, which publishes no text results
